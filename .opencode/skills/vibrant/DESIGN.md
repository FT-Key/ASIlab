## Overview

Modern, bold, playful interface with rich purple primary, warm peach accents, and expressive display typography.

## Style Foundations

- **Visual style:** modern, clean, bold, playful
- **Typography scale:** 14/16/18/24/32/40
- **Typography fonts:** primary=Noto Sans, display=Fascinate, mono=Fira Code
- **Typography weights:** 100, 200, 300, 400, 500, 600, 700, 800, 900
- **Color palette:** primary, secondary, success, warning, danger
- **Spacing scale:** 2/4/8/12/16/24/32/48

## Colors

- **Primary (#7C61D4):** Acciones principales, headings, acentos clave.
- **Secondary (#EAAE87):** Acciones secundarias, highlights cálidos, fills complementarios.
- **Success (#16A34A):** Estados positivos y confirmaciones.
- **Warning (#D97706):** Estados de cautela y alertas.
- **Danger (#DC2626):** Estados de error y acciones destructivas.
- **Surface (#FFFFFF):** Fondos de página y cards.
- **Text (#2F281D):** Texto body y contenido.
